** What is version control?**
Version control is the system for changes file control.
** What is Git?**
Git is a distribute version control system used to track changes in source code during software development.
**What is GitHub?**
GitHub is a cloud based platform where you can store, manage and share git repositors.
**What is Git Bash?**
Command line application for Git.
** What are the main parts of GitHub? 
Repository, commit, Branch, Pull request and Issues.
** What are the stage of Git/GitHub? 
Working directory->Staging area->Local repository->Remote repository.
